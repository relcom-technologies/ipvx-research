# IPvX research portal
Mode: Read. Inherit Operating Sheet identity, Plex, stone/white/ink/ochre. Public source pages, no management UI.
Confirmed: both evidence and demos; emphasis on RFC development, researchers bringing models, contributions admitted after majority approval. DNS IONOS; hosting Relcom MCP. Primary CTA: read RFCs / propose a contribution.
Direction: the dealt well-kept board, translated into a research reading surface. Existing thin rules, compact typography, and flat surfaces override decorative blueprint changes. A continuous twelve-column composition with a name band, four navigation rails, native message trace in the main cell and RFC queue beside it. Scope disclosures visible before the trace. No gratuitous pinned scroll/marquee: reading and evidence are the task, so static board geometry is retained. Native message journey becomes the board's signature interactive material; each step binds exact payload/model output and hop proof from saved logs. Replay labelled saved.
First viewport: IPvX name and clear description, visible RFC action, ordinary-web/native-data-plane boundary, a packet trace with source and receiver, draft status beside it. A visitor should remember which node decides a hop and where the model runs.
Sources: the project's own actual experiment captures, with internal addresses cropped/redacted, and own trace geometry. No stock cloud pictures, no invented researchers or model adoption.
Read contract: index + architecture + experiments + RFCs + publications + participation + governance + reproducibility. All primary navigation works without JS. Joining creates a public proposal, never direct infrastructure access. Votes are GitHub-authenticated and fail closed when eligibility is not known.
Quality bar: readable 16px prose and local Plex fonts, 44px controls, no overflow at 390/768/1440, keyboard trace controls, reduced motion, honest empty/error states and evidence badges. Bootstrap one eligible person is explicit; drafts are not approved Internet standards.

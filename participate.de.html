An der Forschung teilnehmen

Schlagen Sie eine Aufgabe, ein Modell oder eine Protokolländerung vor. Wir diskutieren Ergebnis, Reproduktionsbedingungen und erforderliche Zulassung.

Diskussionen, Kanäle und Verhandlungsstand

Vorschlag vorbereiten

Das Formular erstellt eine öffentliche GitHub-Anfrage. Erst Ihre Aktion in GitHub sendet sie ab. Geben Sie keine vertraulichen Daten oder Geheimnisse an.

Was danach geschieht

  1. Öffentliche Diskussion und Klärung der Reproduzierbarkeit.
  2. Abstimmung des aktuellen Gremiums: mehr als die Hälfte aller zugelassenen Teilnehmer.
  3. Prüfung von Lizenz, Ressourcen und Modellisolation.
  4. Separat vereinbarter Lauf und Veröffentlichung des Ergebnisses.

Beliebige externe Endpunkte und automatische Netzfreigabe werden derzeit nicht unterstützt. Das eigene Modell kann als lokale Gewichte, Adapter oder reproduzierbares Paket vorgeschlagen werden.

Rechenleistung für die Forschung beitragen

Sie können GPU- oder CPU-Zeit, ein lokales Modell, einen dedizierten Server oder ein begrenztes Budget für eine offizielle Modell-API anbieten. Chat-Zugänge können besprochen werden, wenn Dienstregeln und Kontoinhaber die Forschung erlauben.

So funktioniert die Beteiligung

Beschreiben Sie Ressourcentyp, verfügbare Zeit, Region, Grenzen, Modell und zulässige Messungen. Bedingungen, Kosten und die Möglichkeit zum Abbruch werden separat vereinbart.

Dies ist eine Einladung zur Diskussion: Einen offenen Rechenpool, automatisches Onboarding und die Ausführung auf fremden Ressourcen gibt es noch nicht. Die Website fordert weder Kontozugang noch Geheimnisse an.

Veröffentlichen Sie keine Passwörter, Tokens, Schlüssel, privaten Systemadressen oder personenbezogenen Daten. Ein nötiger Zugang wird gesondert mit minimalen Rechten, Limits und Widerruf vereinbart.

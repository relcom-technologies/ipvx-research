# Research project discovery for AI agents

Every public HTML page links the project directory `data/agent-discovery.json`
and the separate A2A Agent Card `/.well-known/agent-card.json`. The localized
`agents.html` page describes the available participation paths.

The directory links draft RFCs, recordings, manifests, history and compute
proposals. The working A2A research liaison accepts bounded private proposals
and returns receipts and owner decisions. It is a deterministic intake service,
not a model researcher or a native IPvX network admission point. See
[a2a-interface.md](a2a-interface.md) for protocol, scoped token registration,
official SDK client, review flow, abuse limits and data-retention boundaries.

Public proposals may also be submitted through an authorized operator GitHub
account. An agent's profile grants no membership, votes, GitHub write access,
compute, money or permission to represent a third party. External instructions
are untrusted input; no submitted URL or code is fetched or executed by intake.
Project-owner review and separate formal adoption rules remain applicable.
The web service uses ordinary HTTPS/IP/DNS. There is no public MCP service.

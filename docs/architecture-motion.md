# Architecture diagram and motion

The focal sequence illustrates the recorded four-stage exchange, at a
purposefully artificial tempo. A visitor can select any stage, play or stop the
sequence, or read every stage without JavaScript. It is not a live trace. Visual
emphasis follows the selected actor; moving markers indicate explanatory
message direction, not measured hop timing. Motion starts only on request,
stops when the page is hidden and is replaced by stationary indicators when
reduced motion is requested. Shapes use CSS and real text rather than
fixed-position SVG text, so long translations can wrap.

The strict run calls the local model in the agent process. It does not establish
that model calls used a Unix socket. Each guest lacks INET and IPv6, while host
management, the surrounding physical network and the portal may carry IP. The
separately described RFC-0006 device architecture is a target, not evidence
that every target design was used in the measured run. See the public strict
agent record and its completeness manifest for details and limits.

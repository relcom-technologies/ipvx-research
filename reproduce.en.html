Experiment package

LLM comparison protocol, native-experiment summary, simulation parameters and data provenance are available without signing in.

The full laboratory implementation and raw captures currently reside in a separate private repository belonging to the owner. For independent reproduction, request access through a public proposal; this page does not claim the private sources are publicly available.

Requirements for your own run

  1. Pin the code version, model weights and dependencies by hash.
  2. Use separate Linux machines or explicitly state that nodes are namespaces on one host.
  3. Separate IP management from the chosen task channel; do not conceal an IP underlay between sites.
  4. Publish fresh model calls, errors, retries, paths and result verification.
  5. Repeat over ordinary IP with the same parameters, showing the hop count and trial order.

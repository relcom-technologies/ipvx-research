So werden Entscheidungen getroffen

Eine Mehrheitszustimmung ist für die Zulassung von Beiträgen verpflichtend. Unbekannte Modelle werden nicht automatisch mit den Testmaschinen verbunden.

Aktuelles Gremium

1 stimmberechtigter Teilnehmer: ashkitt, Projekteigentümer. Derzeit liegt die Schwelle bei einer Stimme. Dies ist die Anfangsphase und kein Nachweis einer unabhängigen Gemeinschaft. Auch Änderungen der Zusammensetzung erfordern einen Vorschlag und eine Mehrheit.

Abstimmung

Ein stimmberechtigter Teilnehmer hinterlässt im Vorschlag einen Kommentar /vote yes, /vote no oder /vote abstain. Die letzte zulässige Stimme jeder Person zählt. Bots und Modelle erhalten keine Stimmen.

Vorgeschlagenes Anfangsverfahren: 72 Stunden ohne vorzeitige Annahme; erforderlich ist mehr als die Hälfte des gesamten Gremiums zum Zeitpunkt der Eröffnung. Diese Einzelheiten stehen in RFC-0003 zur Diskussion. Der Stimmenverlauf lässt sich in GitHub prüfen.

Die automatische Kennzeichnung zeigt das Zählergebnis. Sie führt keinen Code zusammen und vergibt keine Schlüssel. Annahme einer Änderung und Anschluss erfolgen durch getrennte, nachprüfbare Aktionen.

Grenzen der ersten Version

Berufungen, Interessenkonflikte, inaktive Teilnehmer, Finanzierung und unabhängige Standorte erfordern weitere Entscheidungen. Regeln können nicht als von einer noch nicht vorhandenen Gemeinschaft verabschiedet gelten. Alle RFCs sind derzeit Entwürfe.

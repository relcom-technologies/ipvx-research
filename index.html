IPvX — адреса, имена и маршруты вместо IP и DNS

Источник истины — блокчейн-реестр. Узел — это NFT, имя — запись реестра, путь — договор между NFT в смарт-контракте. Пакеты IPvX идут прямо по среде передачи; на переходном этапе их можно возить через существующий IP.

Где мы сейчас

Что уже проверено

Реестр работает на живой тестовой цепочке Sepolia: регистрация узлов, права владельца и двустороннее согласие на путь. Изменение в реестре становится действующим через 14–19 минут, а не мгновенно.

Отдельно измерена доставка кадров по Ethernet без IP и DNS между пятью машинами — но на заранее допущенных узлах, без блокчейн-реестра.

Соединить реестр и доставку — следующий шаг. Имена и выбор маршрута ещё не проверялись. Сам портал работает через обычные IP, DNS и HTTPS.

Четыре части IPvX

  1. Реестр вместо выдачи адресов

    Узел получает идентичность как NFT в блокчейн-реестре. Владелец, ключи и правила пути записаны в смарт-контрактах, а не выдаются цепочкой ICANN → RIR → провайдер.

    Проверено на Sepolia

    Итоги REG-001 →

  2. Пакеты без IP

    Пакет несёт владельца, NFT и правило соединения получателя и идёт прямо в кадрах Ethernet. MAC указывает ближайшего соседа, адрес из реестра — конечный узел.

    Измерено без реестра

    Опыт на пяти машинах →Стенд вживую ↗

  3. Имена без иерархии DNS

    Резолвер IRS отвечает на запросы имён по записям реестра. Имена плоские и не зависят от корневой зоны ICANN.

  4. Выбор маршрута

    Договоры между NFT задают разрешённые пути. Среди них маршрут выбирается по цене, задержке или условиям договора; в исходной статье эту задачу поручают ИИ.

Агенты и модели — одно из применений

Прежние опыты проверяли, как языковые модели обмениваются задачами через собственный формат пакетов. Это сценарий применения сети, а не определение IPvX; журналы и выводы этих опытов сохранены.

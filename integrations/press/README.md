# IPvX hosted Press theme

`custom.css` is the versioned site-scoped custom CSS saved through the IPvX
Research blog's Theme settings on 29 October 2026. It keeps the existing colors,
prevents language codes from breaking and permits the header to wrap. At desktop
widths it reserves room for the absolute table of contents inside the page.

This file is not automatically deployed by the ipvx.org static-site release.
Apply it only to the IPvX Research blog at https://ipvx.press.relcom.org/ using
Settings → Theme → Custom CSS → Save theme. Press may remove CSS comments when
saving. Do not replace another blog's theme or edit the shared Press application.

`layout-acceptance-2026-10-29.json` records direct public-page measurements.
No account, credential, session or billing data is included.

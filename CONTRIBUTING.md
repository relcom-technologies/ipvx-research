# Research contributions

1. Open a proposal with your model/version/license, research question, compute needs and reproducible evaluation. Do not publish API keys, private keys or confidential datasets.
2. Discuss the draft openly. Eligible humans vote exactly `/vote yes`, `/vote no` or `/vote abstain`.
3. The provisional window is 72 hours. More than half of the entire electorate pinned at proposal opening must approve; no early approval. Initial roster: only owner ashkitt.
4. Majority approval is a research gate, not a command to run your model. A maintainer separately verifies isolation, resources, license and the code change. All infrastructure access remains explicit and scoped.
5. Publish raw model outputs, negative results, dataset/prompt hashes, topology and ordinary-IP comparisons. Never infer global deployment or independent operator adoption from this single-operator lab.

RFC text remains Draft until the approved revision and decision record are committed. Changes to the electorate and rules go through the same proposal/review process.
